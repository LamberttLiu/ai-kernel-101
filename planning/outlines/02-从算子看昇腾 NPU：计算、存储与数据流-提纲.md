# 二、先看算子：计算之间有什么依赖？

选择后面会反复出现的四个例子，沿着依赖关系和复用机会展开，避免把分类写成名词表。

## 逐元素计算：以 Add 为例

从 $z_i=x_i+y_i$ 出发，讨论每个输出需要哪些输入，以及不同输出之间是否需要交换信息。由输出之间的独立性，引出数据划分与并行。

## 归约计算：以 Reduce 和 Softmax 为例

一个输出可能依赖多个输入；Softmax 的每个输出又依赖整行统计量。沿着这种依赖追问：为什么不能像 Add 一样，把每个元素完全独立地处理？

# 六、回到第一个算子：为什么从 Vector Add 开始？
