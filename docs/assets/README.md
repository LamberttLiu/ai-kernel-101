# AI Kernel 101：从 Hello World 到 Flash Attention 的 Ascend C 实践

以 Ascend C 为实践载体，从第一性原理理解 AI Kernel 的设计与性能优化。

本页统一图片归档、图表语义、视觉约定与素材来源。图片统一归档到 `docs/assets`，按用途分为三个子目录；迁移只调整路径与图号，保留图片内容与实验数据。

# 可复现与标识

理论模型、实测结果、概念示意分别在图题或注释中明写；尚待测量的曲线不伪装为实测。图表标注篇次／主题、变量与单位、输入和模式、统计量及必要边界，术语与正文一致。

插图以直观图形为主，使用纯色块、细线与统一间距，解释段落留在正文，不做文字卡片式版面。标题中英两行：中文在上 42 px，英文在下 32 px。中文标题使用华文中宋，中文正文与标注使用微软雅黑，所有英文与数字使用 Cascadia Code。正文与标注按上一版层级恢复为 18–34 px，中文在上、英文在下，每组中英字号相同且取整数；框内中英文作为一个整体垂直居中。上下页眉页脚各居中放置浅灰色 `AI Kernel 101 | From Hello World to Flash Attention in Ascend C @LambertLiu` 水印，字号 18 px。以上字号均为最终输出像素中的整数值。实际字体版本与授权记录见[绘图工作流](figures/README.md)。导出前检查中文、上下标、公式、字号和灰度可辨性，避免用颜色作为唯一语义。

| 角色 | 建议视觉约定 |
| --- | --- |
| 背景与文字 | 白色背景；正文、次要说明与边框使用黑白灰 |
| 主要流程、数据与执行对象 | 按作者提供的 `color.png` 取样：天蓝色 `#00B0F0`；浅色由主题色与白色混合，用文字明确资源和层级名称 |
| 约束、依赖、等待与重点 | 同图取样：红色 `#C00000`，必要时与白色混合生成浅红色；配合文字和线型 |
| GM／HBM、UB／L1／L0、Vector／Cube | 各自明确标名，不用颜色代替硬件语义，不因同色视为同一种资源 |
| 搬运与同步 | 搬运用方向箭头；依赖／等待用带文字的虚线或红色标记，注明箭头语义 |
| 模型与实测 | 模型用虚线并写“预测”；实测用点／实线并写“实测”与波动 |

实际绘图需结合对比度调整，不用既有截图的颜色反推硬件语义。概念示意图不提供未经核实的硬件时序或资源规格。

# 源文件与输出

优先用可复现代码生成 SVG、PNG 和曲线。文稿配图代码存放在 `docs/assets/figures/src`，PNG 和 SVG 同名输出到 `docs/assets/figures/gen`，正文以相对路径引用 PNG。外部参考插图归入 `figures`，历史截图归入 `screenshot`，品牌素材及其生成材料归入 `brand`。实验受控数据与原始记录仍放对应 lab 主题，绘图不改变实验数据。源代码、PNG 与 SVG 一并版本管理。

正文插图统一使用 1920×1080 像素画布，白底、非透明，PNG 与 SVG 共用布局；平台适配时再单独调整。以下是内部导出参考，不是平台上传限制：GitHub／长文可使用可缩放 SVG 或清晰 PNG；知乎和公众号检查手机缩放；小红书可另做1080×1440的分页图卡，拆开密集推导。实际输出以平台预览可读性为准，不能为了精简删去关键单位、证据与限制。
