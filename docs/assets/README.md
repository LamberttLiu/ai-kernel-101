# AI Kernel 101：从 Hello World 到 Flash Attention 的 Ascend C 实践

以 Ascend C 为实践载体，从第一性原理理解 AI Kernel 的设计与性能优化。

本页统一图表语义、视觉约定与素材来源。当前五张 PNG 保持原样，本轮不重绘实验截图、不改变数据，也不生成全部平台素材。

# 可复现与标识

理论模型、实测结果、概念示意分别在图题或注释中明写；尚待测量的曲线不伪装为实测。图表标注篇次／主题、变量与单位、输入和模式、统计量及必要边界，术语与正文一致。

建议后续统一使用可公开使用的中文无衬线字体与等宽代码字体，记录实际字体名称、版本及授权。导出前检查中文、上下标、公式、字号和灰度可辨性，避免用颜色作为唯一语义。

| 角色 | 建议视觉约定 |

# 源文件与输出

优先用可复现代码生成 SVG、PNG 和曲线。实验绘图脚本、受控数据与命令放对应 lab 主题，文稿图统一输出到 images；可编辑 SVG 本身也应版本管理。有实际图时再增加源文件，不预建空绘图工程。

下面是内部导出预设，不是平台上传限制：GitHub／长文优先可缩放 SVG 或清晰 PNG；知乎和公众号准备约1600像素宽的长文图并检查手机缩放；小红书可用1080×1440的分页图卡，拆开密集推导。实际输出以平台预览可读性为准，不能为了精简删去关键单位、证据与限制。
