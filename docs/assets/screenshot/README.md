# 归档与引用

截图保留原始文件名，正文使用相对路径引用。记录采集或上游来源、对应篇章、可核对的软件／设备版本、公开权利，以及必要的裁剪说明。原始运行数据与分析仍属于 lab，截图只提供其可见范围内的证据。

公开前核对账号、配额、认证材料和私人信息。需要裁剪时，保留原件与上下文，另存可公开副本；裁剪不能改变实验事实或掩盖失败。来源或许可不明、未经授权及含私人信息的素材先留本地，不加入公开素材。
